# Quiz Arena

Локальная веб-игра в духе SIGame: кастомный экран входа, до пяти команд, сетка вопросов и модификаторы ставки. Админка редактирует конкретный пакет — оформление, темы, вопросы и правила модификаторов.

Ничего ставить не нужно: это статические HTML/CSS/JS. Партии и пакеты живут в `localStorage` браузера.

## Как запустить

Из папки `quiz-arena`:

**Вариант 1 — Docker (если уже стоит Docker Desktop):**

```bash
docker compose up
```

Откройте http://localhost:8088

**Вариант 2 — Python в WSL:**

```powershell
.\start.ps1
```

или:

```bash
python3 -m http.server 8088 --bind 0.0.0.0
```

Не открывайте `index.html` как файл: модули ES требуют HTTP.

На Vercel это статическое приложение: игра и админка работают в браузере. Загрузка медиа на хостинге сохраняется в IndexedDB этого браузера; локальный `server.py` по-прежнему копирует файлы в папку `media/`.

## Как играть

1. На главной выберите пакет (демо «Своя игра» уже лежит в памяти).
2. Экран входа берёт название, цвета, текст и код из пакета.
3. Создайте 2–5 команд и укажите капитанов.
4. Ведущий открывает клетку, выбирает модификатор, показывает вопрос. **Правильность засчитывает ведущий** («верно / ошибка» или свои очки вместо номинала).
5. В любой момент: **Очки ведущего** на поле или клик по карточке команды — накинуть или снять баллы.

В админке у каждого вопроса можно прикрепить **картинку, аудио и видео**: перетащите файл в слот или на карточку вопроса. Сервер **копирует** его в `quiz-arena/media/<пакет>/<вопрос>/`, а не оставляет путь к оригиналу. URL тоже можно вставить вручную.

Модификаторы по умолчанию: обычный, без капитана ×1.5, только капитан ×1.5, двойная ставка, ва-банк, кот в мешке, аукцион, пас сопернику, все команды, без права на ошибку.

## Админка

`#/admin` — список пакетов. Можно создать новый, скопировать, экспортировать/импортировать JSON, править вход, сетку и модификаторы.

Чтобы сделать вечер под конкретную тему, откройте пакет → **Вход и оформление**: заголовок, приветствие, имя ведущего, кнопка, PIN, цвета, фон.
